Student Management System (Python & MySQL)

A CLI-based Student Management System built using Python and MySQL. This application performs full CRUD (Create, Read, Update, Delete) operations with parameterised SQL queries for secure database interaction.

Features
- ➕ **Add Student:** Insert new student records into MySQL Database.
- 📋 **View Students:** Fetch and display all records.
- 🔍 **Search Student:** Find specific student details using Roll Number.
- ✏️ **Update Student:** Modify email and phone numbers of existing students.
- 🗑️ **Delete Student:** Remove student records securely.

Tech Stack
- **Language:** Python 3.x
- **Database:** MySQL
- **Driver:** `mysql-connector-python`

How to Run
1. Install dependencies:
   ```bash
   pip install mysql-connector-python

   Update your MySQL password in main.py.
